# 科研设计与实验证据的复测用例

以下三个案例均为合成材料。分别开一个新对话，只发送对应的输入框内容。如果使用独立 Prompt，将对应 Prompt 全文贴在输入前。取得回答后再看末尾判据，记录模型、日期和回答，便于比较不同版本。

## 1. 只有摘要

可使用研究 Skill 或 Prompt A。

```text
旧工作只有摘要一句“用过去 15 分钟的到达量预测当前排队等待时间，并报告平均绝对误差”。
我在同一任务中对长队样本的训练损失使用两倍权重，推理时输出等待时间。
我能把处理长队样本的机制写成与旧工作的创新差异吗？仅依据给定材料判断。
```

## 2. 按预设门槛作决定

可使用研究 Skill 或 Prompt B。

```text
温度仪表校正的 C 版协议事先指定，只有三个种子各自的测试 MAE 比固定偏置
至少低 0.10 °C，才采用随温度变化的偏置。固定偏置已在验证集选定并冻结。
两者共用同一检查点，使用相同划分、标签和后处理。按种子 2、5、9 配对的
测试 MAE（°C）分别是固定偏置〔0.96，0.94，0.98〕，随温度变化的偏置
〔0.90，0.91，0.96〕。这个版本是否采用新偏置？还需跑什么？
```

## 3. 从机制差异追到实验归因

可使用研究 Skill，或先用 A 再将已核实的差异交给 B。

```text
班车到达时间校正任务的两条公式分别为旧方法（1）$\hat y=x+b$、
新方法（2）$\hat y=x+b_s$，$s$ 是早班或晚班。两者用同一组原始预测 $x$，
偏置均在验证集拟合并冻结。表 1 只给全日测试 MAE，旧 4.0 分钟、新 3.8 分钟。
我的主张是，全日改善主要来自晚班。测试记录保存了每条记录的班次、标签和两种预测。
这两种方法差在哪里？现在能写什么？最低成本的下一步是什么？
```

## 核对判据

| 用例 | 回答需要满足的条件 |
| --- | --- |
| 只有摘要 | 指出 MAE 是报告指标，旧作训练权重未知。可以描述自己的设计，将两者的差异和首创性保留为待核实。给出能核实旧作权重的最小材料。 |
| 预设门槛 | 按种子算出改善量依次为 $0.06, 0.03, 0.02$ °C。三个都未达到 $0.10$ °C，当前版本保留固定偏置，已有材料足以决定。 |
| 机制与归因 | 定位全局偏置和分班偏置的差异。表 1 只支持全日平均改善。用相同测试记录计算每条记录的绝对误差改善量，再按班次统计其均值。若全日 MAE 按记录等权计算，按班次记录数加权得到各班对全日改善的贡献。用未舍入值核对两项之和，注明采用的“主要”判据与分析范围。 |
