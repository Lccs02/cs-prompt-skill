# 科研设计与实验证据

根据用户当下要做的决定选择入口。把用户已经给出的论文、公式、实验表和协议直接填入相应步骤，空缺项按现有依据处理。

| 用户要做的决定 | 执行方式 |
| --- | --- |
| 判断候选机制与最接近工作有何差异、是否值得验证 | 阅读并执行 [最接近工作与研究缺口核查](references/closest-work-gap.md) |
| 判断已有证据能支持哪句话、是否值得再跑实验 | 阅读并执行 [核心主张与实验设计](references/claim-experiment-design.md) |
| 同时判断创新差异和实验充分性 | 先核查文献，把已证实的差异、可证伪假设及成立条件交给实验步骤。存在歧义时，分别说明各读法对实验的影响。 |

直接使用与问题相符的步骤。用户只给实验表时，从表中已有的对照开始。用户同时提供多个版本时，用明确的版本标识把数值、结论和证据位置关联起来。

先给能据此作出的决定。涉及论文表述时，用一行交付 **可写的主张｜证据位置｜成立条件或反例｜待核实事项**。用户要求润色时，可把这一行及原文交给「论文发布会原则」。
